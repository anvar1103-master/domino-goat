# Козёл онлайн

Сервер для игры в домино «Козёл» с друзьями. Он раздаёт кости, проверяет ходы и играет за ботов на свободных местах. Каждый игрок видит только свои кости.

## Запуск на своём компьютере

Нужен Node.js 18 или новее.

```
npm install
npm start
```

Откройте http://localhost:3000. Друзья в той же Wi‑Fi сети могут открыть http://АДРЕС-ВАШЕГО-КОМПЬЮТЕРА:3000.

## Размещение в интернете (бесплатно, Render.com)

1. Заведите аккаунт на github.com, создайте репозиторий и загрузите в него все файлы из этой папки.
2. Зайдите на render.com, войдите через GitHub, нажмите New → Web Service и выберите репозиторий.
3. Настройки: Runtime Node, Build Command `npm install`, Start Command `npm start`, тариф Free.
4. Через пару минут Render даст адрес вида https://kozel-xxxx.onrender.com. Это и есть ваша игра.

На бесплатном тарифе сервер засыпает после 15 минут без игроков, первое открытие после этого занимает около минуты.

## Как играть

1. Откройте адрес сервера, нажмите «Играть с друзьями онлайн», введите имя и создайте комнату.
2. Нажмите «Пригласить» и отправьте ссылку друзьям или продиктуйте код из 4 символов.
3. Рассадитесь: сидящий напротив — партнёр. Пустые места займут боты, их уровень выбирает хозяин комнаты.
4. Хозяин нажимает «Начать игру».

Если связь пропала, игра сама переподключится и вернёт вас на ваше место. Пока вас нет, за вас ходит бот.

Если игра открыта файлом на телефоне, а не с сервера, впишите адрес сервера в разделе «Адрес сервера».
